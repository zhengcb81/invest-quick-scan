# Retired task-receipt contract

The task-receipt v2 workflow, P01 closeout gate, and recursive dependency verifier were retired on 2026-09-29. This path remains as a migration notice only. The former specification and implementation are preserved at [docs/implementation/archive/task-receipts-v2-legacy/README.md](../archive/task-receipts-v2-legacy/README.md).

Historical P00/P01 receipts, reviews, sidecars, manifests and logs remain unchanged at their original paths. They are read-only records and do not establish current task or milestone completion. New implementation batches record HEAD, changed paths, affected test commands/results, sample hashes, temporary-root cleanup and unresolved items in `progress.md`; independent reviews occur at major milestones and high-impact boundary changes.
