## 推荐的设计方向

- 保持近白背景、白卡片、深灰正文和单一蓝色主色。主色用于当前导航、链接和当前阶段的主按钮。
- 普通说明、需处理、明确失败、已核验完成分别有文字及颜色语义；不能所有缺项都用同样蓝条，也不能把unknown换成绿色完成。
- 正文约14px/1.6，研究理由可15px/1.7，次要元数据13px；使用有限的4/8/12/16/24/32间距。配置textarea单独处理高度。
- 题目、分数、理由、重大缺口留在主层；完整JSON、哈希、精确时间和协议诊断放详情。公司名称和代码优先，唯一ID仍可复制和核对。
- 用现有轻量前端渐进拆分状态提示、公司选择、记录展示、表格和弹层组件；不为设计整改迁移框架或增加花哨大屏。

这些是可讨论的基线，不是已实现的设计系统或可访问性合规认证。视觉报告有更完整的组件规范和具体例子。
