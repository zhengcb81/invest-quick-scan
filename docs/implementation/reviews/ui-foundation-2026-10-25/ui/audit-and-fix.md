## 本轮修复

- 基础必做模块从当前题库policy的common/diagnostic默认规则派生，前后端同源；当前 common24 + 杜邦7 + 五力5 = 36。模块仍独立版本，diagnostic不进入核心汇总。没有24题上限。
- 显式 `--applicability-input` / `IQS_APPLICABILITY_INPUT` 支持真实APPLIC snapshot：校验原catalog/roster SHA、完整公司×模块范围、重复、四态、合成来源等；决定传递到前端。不自动加载旧demo或用公司名猜行业。
- 题库页完整浏览61个信息题面；公司答案显示扫描时间、信息截止和逐题模型字段。源没有模型时显示未记录，不按配置猜测，不补旧版本。
- 矩阵图例/详情/数据说明、版本页计数/差异均从实际数据派生；明确区分current.json旧发布包与当前源router2.5。
- 生成来源清单增加全部评分模块与12原答案，当前88项原始字节SHA逐项一致。
- 启动说明默认不重复跑整套测试。总控另提供主仓薄入口。

## 尚未完成的产品能力

界面现在可供浏览现有公司、题库、历史草稿和筛选。它尚未自动读取生产owner新封包、StockWiki实时查询、持续刷新或自动运行全池。所有公司入名单并不等于都已完成问答；没有答案时如实留空。本轮不以UI可用宣称全池扫描、金融准确性或生产数据库资格通过。
