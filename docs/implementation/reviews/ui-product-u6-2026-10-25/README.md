# U6：公司快扫工作台操作闭环

本轮把固定扫描包控制台扩为公司准备、完整公司组批跑与异步交付。使用入口是根[README](../../../../README.md)和[产品部署契约](../../dashboard-product-contract.md)。本目录只归档薄工程证据；最终独立结论与源码绑定见`review/final.json`，文件完整性见`integrity.json`。

## 本轮交付

- 公司选择、信息截止、quick/full、可信模块profile及真实主体/证券选择；所有公司基础36题动态组合。未知分类不猜，多挂牌不猜股类。
- 复用原StockWiki身份快照、发行人主体初始化、原路由/C06/确认/StockQA准入；异步准备、阶段错误与只读接续。当前服务器完整UTC快照与答案信息截止日分离，预览/确认复用冻结时间；旧完成结果幂等，旧未执行且缺时间字段的候选重新预览。
- 按完整公司组选择/全选、批次预览与持续执行；同公司经营和证券范围顺序执行，跨公司有限并发，按原状态暂停与恢复。2000公司本地预览/登记不启动4000次原检查CLI，实际每次派发仍须原守卫。
- 异步按原scope/批次入库，精确封存包字节与历史release投影，独立绑定接收目标后原导入及exact ACK。父任务仅存薄摘要，不复制题目账本、答案或ACK权威。
- 跨进程非阻塞配置/控制锁、进程退出后的显式恢复、长调用不持全站锁、批/交付记录16MiB读写一致上限。5000scope记录约6.26MB，可回读；超限保留旧文件。
- 静态GET/HEAD同时守住Windows绝对盘符、编码、ADS、设备路径、软链接/reparse与SPA fallback边界。
