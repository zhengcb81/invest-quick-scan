## 范围与入口

由 IQS 自己在正常 CLI、HTTP 和后台作业的失败出口保存原状态与脱敏原因，使用既有 feedback-observation/1。本计划处理 owner-cause-lost、business-failure-classified-expected 及同类普通失败。StockQA 负责逐题状态、支付事实和未发送恢复；跨仓只消费公开错误和引用。
