# 真实研究实验的准确性评估规则

2026-10-16；在向盲评者展示任何模型答案前冻结。适用S1R及其后续显式修订，生成API费用和评审harness费用分开记录，后者未计价时不能称总成本精确已知。

1. 先评质量，再解盲看模型、策略、耗时、费用。评审输入包含匿名逐题完整答案、原题/锚点、统一公开证据及截止日；不含生成模型、策略、运行路径、耗时、计量或费用。私有映射在总控留存。评审者可看独立客观参考，生成模型不能看私有rubric/gold。
2. 标量参考的固定分母为实验前锁定的10个主原子命题。按主体、指标、期间/时点、币种、单位和口径核对，允许正确换算及披露精度舍入。跨题重复引用只计一次；未提及是覆盖缺失，不能算正确。分别给出正确/矛盾/未覆盖，并标明正确率的分母。
3. 其余可核事实逐条记录：supported、contradicted、unsupported、not_assessable；保留原答中的具体短命题及source_id/参考原子链接。来源URL存在不等于支持结论。错主体/错期间/错币种量级/错会计分母/未来信息均属具体事实错误，不能被其他正确数字抵消。
4. 推断与事实分开：例如广告增长不能单独证明留存/份额/定价权；经营利润率不是ROIC；现金及证券不必全是无约束资金；Cloud增长不等于AI为股东创造净价值。合理且有边界的推断不因没有唯一答案而算事实错，但不得伪装成已证事实。
5. 每题语义覆盖标为充分回答、部分回答、审慎证据不足、缺失/未解析。12个原题槽均保留，不能只比较成功题；结构完整不等于金融完整。参考标量覆盖率也不等于问题覆盖率。审慎拒答可体现准确性，但若大部分问题未知，仍不能宣称具备海选效用。
6. 没有唯一1–10黄金分。对评分只评价理由与证据/锚点的支持关系，标为合理、依据不足、过度自信或未评分，并注明争议。不得把模型之间评分相同当正确，也不得把不同评分直接当错误。周期低谷、已核正常化能力、未兑现假设及生存风险分别看。
7. 初答、修订、拒绝、未完成、资源受限和所有真实物理发送保留。协议/格式拒绝不自动等于金融答错；未留存的失败正文标记不可复核，不能补造。只给出最终合法答案时，必须说明评估范围不覆盖丢失的早期草稿。
8. 主结论先列事实矛盾/不支持断言、问题覆盖与合理拒答，再列速度、原生HTTP/token/cache、公开价估算。缺计量留空，预留不是实付，现金账单未知。单公司/两重复是小样本证据，不宣布通用最优或关闭Financial/G3/F05。

一次集中盲评是整个实验的大节点。只有实质分歧或新结果需要补评，不为每个小改动新增审查门。输出的完整匿名判定及解盲映射留档，以便下一轮复算与复核。
