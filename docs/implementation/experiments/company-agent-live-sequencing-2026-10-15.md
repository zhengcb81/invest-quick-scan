## 比较与计费口径

- 三策略：固定三题包、自由公司 agent、证据驱动公司 agent。S1 共用冻结短证据；S2 各自检索，搜索方案显式记录。Brave 为原主搜索，不暗换工具或模型。
- 准确性优先：严重事实错误、证据支持的正确覆盖、评分依据及未知的处理；完整 JSON、模型一致或自我审查次数均不等于准确。
- 成本：累计所有成功、失败、补问、复核、搜索及预热；按实际 usage 与当时可核验官方报价估算，套餐消耗与现金费用分列，未知不填零。单位成本用每个合格回答计算，同时保留总费用与全部原始题目分母。
- 速度：记录公司真实墙钟时间、各请求延迟、排队及补问时间；请求耗时之和不冒充并行墙钟时间。
- 缓存：供应商实际 cache usage 与本地搜索/答案复用分列；缓存字段缺失记 unknown，不把 HTTP 零调用当作供应商 KV 命中，不假设新会话绝对冷缓存。
- 失败：拒绝、限额、截断、超时及发送结果未知全部留档。未知态先核原 attempt，不盲重试；备用模型形成单独可追溯分支，不污染同模型策略比较。

原首轮上限仍为 318 次模型 HTTP；S0 至多 24 次、每模型 6 次，S1 144 次，S2 90 次，其余按原预注册。用户已允许超过总金额提醒线后通知并继续，不取消单试验上限和发送前预留。
