## 已固定的默认语义

- 有效性区间使用UTC、右端不包含：`now < valid_until`才仍在TTL内；恰好到期即stale。日期型财务期间不能伪装瞬时时间。来源公布晚于严格截止日不可用。
- 新鲜度还要求身份/作用层、题义/锚点、财务期间、检查等级和事件状态兼容；TTL是上限。原始信息日期未知不得靠imported_at补齐。
- unknown保持未知，同时允许`next_retry_at`冷却，不能算有效覆盖；规则需要的N/A默认unknown，除非策略显式定义适用人群。空all/any规则视配置错误，不默认为全通过。
- all三值逻辑：任一fail则fail，其余存在unknown则unknown，否则pass。any：任一pass则pass，其余存在unknown则unknown，否则fail。质量总分与质量型白名单的critical gate在普通条件组合外单独计算，不能靠OR绕过。普通产业候选和恢复观察没有隐含质量门槛，不能因为gate未过就删除对象。
- 关键风险沿用当前IQS_12/13/16及实际类型替代；有效1—3为重大问题，缺失/低置信度/未审核/N/A为未解。此默认不因新增screening模式而降低。
- 旧严格审核和新screening可用性分别显式标识；没有迁移契约不自动提升资格。事实、来源和模型回答状态分别记录，不能合成一个success布尔值。
- 用户顺序和预算只读自StockQA。默认策略变更用于新运行；要求热更新时记录派发边界和策略版本，不影响已派发或已完成题。
- 名单按独立公司计数，市场覆盖数允许重叠；父子上市主体独立保留。60/25/15是候选构建的可调起点，不是收益模型或强制行业配额。

## G0前必须形成的决策工件

| 决策 | 拥有任务 | 交付内容 |
|---|---|---|
| metric、题目/类型替代、作用层和版本 | C02 | 显式映射；不可比项目保持不同metric或cohort；不猜全市场统一尺度 |
| 响应状态、检查等级、规则schema | C03 | 枚举、条件、错误码、未知/不适用真值表和兼容策略 |
| 信息时点、刷新代次、租约/回执状态 | C04 | 状态转移表及禁止转移；任务键与请求缓存键分开 |
| 搜索能力、故障类别、模型/费用策略 | C05 | 实际价格来源与版本、统一重试拥有者、冷却恢复条件 |
| 跨仓交换、导入、查询与补扫接口 | C06 | 拥有者、版本、hash边界、ACK、错误语义；预留facts不启用 |
| 配套部署、统一启动与就绪等级 | C07 | 独立环境/公开控制入口、配置归属、实际加载hash、幂等启动、预算连续性及G6要求 |

实现者可决定局部命名、函数分解、索引等技术细节，并记录理由。改变上述语义时提交一页变更记录：旧规则、新规则、必要性、受影响任务/测试、数据迁移和回退方式。更新场景预期需要解释业务含义变化，不能仅写“原测试失败”。

G0由实施负责人安排设计审查，不要求每个命名都向用户请示。涉及用户已明确偏好或新增费用/范围时，遵循已有授权；没有答案的依赖只挂起相关任务，继续可独立推进的工作。
