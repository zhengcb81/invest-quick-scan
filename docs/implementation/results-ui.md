# 企业快扫结果 UI

2026-09-22，计划1.4.0，待实施。UI是完整交付的必需项，由StockWiki扩展既有Web界面；复用同一quick_scan数据库、查询服务和启动控制，不另建前端权威库或LLM客户端。

## 1. 三个主要界面

| 界面 | 用户要完成的事 | 必需内容 |
|---|---|---|
| 股票池列表 | 从约2,000家公司快速找到候选 | 名称/代码/别名搜索，市场、公司类型、行业、生命周期筛选；分项评分条件、质量白名单、恢复观察、数据状态；排序、分页、保存筛选 |
| 企业详情：评分与依据 | 看清分数、优点、风险及变化 | 身份与全部挂牌、业务摘要、分组评分表、每题依据与来源、关键风险、周期/反转观察、优势与变化判断、逐项时效 |
| 企业详情：事实与产业链 | 找到企业在链条中的位置 | 细分业务、产品、设备、材料、供应商/客户、下游应用及关系方向/阶段/时期；跳转相同细分方向的公司和研究技能 |

运行进度与设置继续沿用X04/X06。进度页能进入已完成公司的结果，结果页能回到对应运行；用户不必打开JSON或切换项目目录。事实页在G4验收后启用，不延后已有评分结果的浏览。

## 2. 股票池列表

默认列为公司、市场/代码、行业、已验证的评分摘要（缺失则明确标记）、恢复观察/关键风险、有效题覆盖与更新状态。用户可添加关心的分项分数列，用明确的AND/OR及大于/大于等于条件筛选，例如“指定指标>8”；界面展示命中、未命中或待核实及原因。

“全部公司”“质量白名单”“恢复观察”“待补数据”是相互独立的视图。全部公司不暗含质量门槛；周期低谷公司可在恢复观察中出现，即使当前质量低分或未知。人工关注作为用户名单状态保存，不改公司评分。修改阈值、搜索、翻页和排序仅查询现有数据，不调用LLM。

公司行以entity_id去重；A/H/ADR代码任一命中同一公司详情。证券层的估值/价格/币种/日期在选择具体证券后显示，不能拼成一份公司价格。统计独立公司数，同时保留市场覆盖重叠说明。

默认每页50家公司，服务端按冻结查询快照/稳定排序键分页，单次页面最多请求100行。新增或更新数据时提示刷新；翻页不静默混用不同快照而重复/漏行。约2,000家公司全量fixture验证计数、筛选及分页；记录环境与耗时，不向浏览器一次发送所有题目/来源详情。

## 3. 企业详情的阅读顺序

1. 顶部：公司身份、挂牌证券、行业/类型/阶段、信息时点和有效覆盖；简短摘要来自已存记录，不因打开详情临时生成。无摘要就显示未采集。
2. 首屏：关键优点、关键风险、周期低谷/恢复观察，以及哪些数据尚缺。标签引用对应题目/观察；恢复标记不修改低分，不掩盖资金时限或结构性衰退风险。
3. 评分表：通用核心、公司类型/行业/阶段补充、杜邦与五力诊断分组。每行显示题目、1—10分或明确状态、短依据、信息日期、证据置信度、模型和metric/rubric版本；可展开锚点和来源链接。类型替代题显示对应关系，不将被替代题再计一次。
4. 优势与变化：分别呈现优势持续条件、被削弱的机制、产业变化机会/威胁和跟踪条件；只呈现已验证字段，尚未实施的字段显示能力未就绪，不用主题关键词补写乐观结论。
5. 历史：查看已保存观察并与当前对照。只有同实体/作用层/metric/rubric且口径可比时才显示分数差；题义或口径改变显示不可直接比较。区分信息日期、采集时间、入库时间；不将重新入库当作更新事实。

不得自行计算“万能总分”。已有质量、成长等指标按各自已验收定义展示；杜邦、五力和恢复诊断不混入均分。缺数据、未评分、不适用、低置信度、过期分别标记，未知不得变为0或5分。过期8分可查看，但不能默认作为当前有效8分参与规则。证据置信度与投资分数分列。

## 4. 事实和产业链视图

关系用可搜索表格先交付，无需大型关系图。显示“公司—关系—对象”、关系方向、量产/在研等阶段、分部/时间、短依据与来源；同词出现不等于供货或生产。支持从“使用某设备”的公司跳到该设备相关候选，同时保持使用者和生产者角色可辨。

切换到事实页或主题搜索不自动补扫。显式“更新本公司/补充所选字段”调用既有缺口预览，展示范围、复用项和已配置预算，再由用户发起；不重复要求输入已保存参数。缺配置跳设置；数据库可读但模型不可用时，仍能浏览。跳转研究技能只交接当前候选/关系/来源，不在后台自动启动全池或深研。

运行与维护页用表格展示用户顺位、当前使用模型、全局/组并发、冷却原因/可知恢复点、已完成/待补/结果不明题数；“额度等待”不能显示为整个公司扫描失败。配置编辑调用StockQA同一接口，详情和比较列始终使用各题实际模型。参见[模型策略](../../references/model-policy.md)。

## 5. 空态、可靠性与交互质量

- 新公司暂无结果、无筛选命中、部分题缺失、全部过期、服务不可用分别有准确状态。仅一次空结果不能宣称该行业无标的；已有结果不得因执行器离线而消失。
- 链接可复制并以entity_id稳定定位详情；刷新/浏览器后退保留筛选、分页和所选证券。桌面1366×768和窄屏390×844均可读，窄屏采用卡片/受控表格滚动。
- 键盘可操作筛选、打开详情和返回；焦点可见。分数/风险同时用文字标记，不只依赖红绿颜色。长名称、中文、长依据和空值不遮挡操作。
- LLM短文本安全转义，不执行其中HTML/脚本；来源只允许安全HTTP(S)跳转，不内嵌或抓取来源全文，不在URL/页面泄露密钥。
- 页面只呈现查询层已判定的规则、新鲜度和恢复状态；不能在浏览器复制另一套评分/时效规则导致CLI与页面分歧。

## 简洁交互与三维查看

主导航固定为股票池、运行与维护、设置；详情用概览、评分依据、事实关系、历史与模型四个页签。默认表格和文字，重要列靠前，低谷恢复/缺口易找到，不使用装饰动画或雷达综合分。选2—5家公司可打开同字段并排表；时间选择扫描快照，模型选择明确对照组。不同题义、信息日期、期间或模型显示不可比原因，不把分差直接称作公司改善。实际比较服务由W14提供，UI不重写逻辑。维护页显示自动新增/待核实/配额/来源，也提供手工加公司、pin及禁止自动恢复。详细规则见[全局契约](../system-contract.md)。
