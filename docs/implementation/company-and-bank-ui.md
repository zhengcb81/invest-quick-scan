# 公司与题库浏览器：当前可用范围

2026-10-25。此页说明实际可用产品及数据，取代把历史施工包验收误认为全股票池已经完成扫描的理解。

## 打开使用

在 invest-quick-scan 根目录运行：

```powershell
python scripts/open_dashboard.py
```

终端打印本机网址，默认 `http://127.0.0.1:8765/#/bank`；端口已用时会打印其他可用端口。Ctrl+C停止。入口复用同级 `iqs-question-bank-ui-lab` 的服务，启动时重建只读展示数据，不执行测试、不调用LLM或搜索、不修改StockWiki数据库。

`--no-refresh`仅查看已构建快照；`--ui-root`指定UI源码目录，`--data-root`指定IQS数据根；`--plan`只查看启动命令。独立VIEW导出浏览器仍用 `view_quick_scan.py --bundle ...`，两种入口的数据范围不同。

## 已接入什么

| 内容 | 当前实际范围 |
|---|---|
| 公司名单 | 已导入的214个实体，209 verified、5 provisional；并非目标约2000家已经全部建立 |
| 评分题库 | 当前catalog的48个模块、222题，含完整题面、依据与评分锚点 |
| 基础必做 | common + dupont + porter，当前24+7+5=36题；数量动态派生，模块/题目ID与历史版本保留 |
| 信息题库 | facts.json的61题可浏览，不评分，也不代表这些公司事实已经采集 |
| 历史草稿 | 12次旧扫描、关联11家公司；288条回答中177条有分、111条证据不足 |
| 未匹配身份 | 一份“中微公司”历史草稿保留未绑定，不凭名称强并入可能混淆的实体 |
| 时间与模型 | 保留原扫描时间；原记录没写模型就显示“未记录”，不能补猜。新薄草稿会保存实际回答模型/提供商 |

题库内容、公司矩阵、公司详情、选股器和版本页均可使用。所有公司默认显示基础模块适用；没有行业/阶段路由依据的其余格子保持未评估。显式接入适用性快照必须通过其原公司名单、catalog哈希和完整范围检查，不能把历史研究快照自动冒充实时生产判断。

## 基础题如何执行

新快扫默认覆盖完整基础集合，不再从旧24题文件取默认输入。只验证出题、零模型调用：

```powershell
python scripts/question_sets.py basic --output runs/basic-questions.json
python scripts/thin_scan.py --company "宁德时代" --out runs/basic-dry-run --dry-run --as-of 2026-10-25
```

`basic_questions.json`是StockQA兼容导出；`main_questions.json`及显式 `--questions docs/implementation/questions-24.json`保留历史兼容用途，不是新扫描的完整基础模板。完整类型/行业/阶段组合与新2.5冻结路由命令见SKILL.md。quick/full都保留基础框架；题数预算只能延后选配题，预算连基础/关键风险都容不下则明确报错。

杜邦和五力逐题回答，但不混入核心质量均分。个别比率对银行或商业化前公司没有经济含义时，保留题目、说明依据并标不适用，不能强行打中间分；缺资料仍是证据不足。

## 还没完全产品化的部分

当前是能用的本地只读浏览器。203家公司没有已关联的历史扫描；上述12次扫描都未绑定题库版本，不能参与严格版本化比较。最近共享引擎的真实ready封包、StockWiki导入/ACK和生产结果尚未接入本UI，不能据题库页和空公司页宣称所有公司都已有评分。

页面打开、筛选和浏览不启动扫描。目前也没有完整的生产任务控制、自动刷新全池、加公司或模型设置操作台。先使用现有浏览能力；后续沿PWF接StockWiki ACK与生产查询结果，不在UI另造评分或权威数据库。任意未来版本的锚点差异比较还需按冻结artifact版本补齐，本轮没有把它宣布为全面验证完成。

本轮只运行受影响的定向测试及真实浏览器检查，整节点统一独审；没有重新跑小时级全套或付费扫描。最终结果见 `reviews/ui-foundation-2026-10-25/` 的验收证据及根PWF。
