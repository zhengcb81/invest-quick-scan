# 买方问题的选择与诊断工具

## 先围绕经济判断选题

默认核心为24题，完整文字、证据要求及1／5／10锚点见 [buy-side-questions.md](buy-side-questions.md)。选择标准是：该题是否可能改变对企业价值、永久损失或进一步研究优先级的判断；是否有可通过公开搜索核验的证据；是否与其他题提供不同信息。

核心问题刻意区分以下层次：

- **客户价值与公司利润**：客户愿意买，不等于利润留在公司；还要观察供给和客户、供应商的分配力量。
- **单位、存量与增量回报**：IQS_03评价成熟单元能否赚钱；IQS_10评价全公司存量资本回报；IQS_21评价新投入能否继续创造价值。不能用老资产的高回报证明扩张回报也高。
- **经营质量与财务真实性**：真实披露也可能揭示差的业务；好看的利润也可能来自失真会计。IQS_10、11、12分别评价回报、兑现与可信程度。[CFA关于财务报告和盈利质量的区分](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/evaluating-quality-financial-reports)支持这一分析区分，但本清单的题目和权重由本skill自行设计。
- **公司价值与每股价值**：并购、增发或股权激励可能让公司变大而普通股东回报变差；资本配置与估值均用适当摊薄后的每股口径。
- **增长、质量与价格**：成熟公司可以具备好业务和合理价格；高速增长也可能消耗价值。三者分开评分，不预设某类公司天然更好。
- **价格余地与便宜倍数**：先观察当前价格需要什么经营结果，再看压力下普通股剩余价值和回报实现机制。低PE可能来自峰值利润，低PB可能来自资产损失。
- **当期低谷与长期能力**：暂时亏损或指标恶化不自动否定正常化回报与仍保留的优势；能否恢复、能否撑到恢复及现有普通股能否受益，需要独立判断。使用[恢复观察](recovery-watch.md)，不靠上调低分或忽略风险保留候选。

题库是初筛工具，不构建未经验证的利润模型或资本成本点估计。资本成本、正常化盈利、维护投入、压力回收值只能用有依据的区间或明确推断；关键输入查不到就保留空分。公开信息搜不到是证据缺口，不能自动评价业务差。

## 杜邦：需要解释资本回报时追加

源文件 `questions/diagnostics/dupont.json`。适合的问题包括：ROE突然提高但现金未改善，或需要判断回报来自经营改善还是杠杆／权益缩减。不要因为公式存在就要求每家公司每次都答。

| ID | 诊断项目 |
|---|---|
| DUPONT_01 | ROE水平、来源与持续性 |
| DUPONT_02 | 净利率 |
| DUPONT_03 | 总资产周转率 |
| DUPONT_04 | 权益乘数 |
| DUPONT_05 | 经营利润率 |
| DUPONT_06 | 利息负担系数 |
| DUPONT_07 | 税负系数 |

三因素：`ROE = 净利润/收入 × 收入/平均资产 × 平均资产/平均权益`。

五因素：`ROE = 净利润/EBT × EBT/EBIT × EBIT/收入 × 收入/平均资产 × 平均资产/平均权益`。

使用同一期间、币种和经济边界；合并资产与含少数权益的权益配合含少数股东损益的税后净利润。归母ROE单列，不能混入恒等式。调整EBIT与法定EBT不能直接拼成严格分解。资产／权益优先可得的合理期间均值，重大并购、增发与回购造成的分母变化必须解释。负或近零分母时不机械评分。

银行保险的利息属于经营要素，普通资产周转或EBIT分解往往不可比；使用适用的权益资本回报、风险成本、资本生成等类型题。REIT注意折旧和重估，控股集团注意权益边界与可上缴现金，商业化前企业不以失真的亏损比率评价全部经营质量。

杜邦用于解释回报来源，不代表杠杆越高、周转越快或税率越低越好。可参考 [CFA财务分析技术](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/financial-analysis-techniques)的比率分析范围；本skill仍以资本回报的经济质量为判断对象。

## 五力：竞争结构或利润归属不清时追加

源文件 `questions/diagnostics/porter.json`。适合的问题包括：收入增长而利润持续被挤压，或表面寡头行业却没有超额回报。

| ID | 诊断项目 |
|---|---|
| PORTER_01 | 现有竞争者竞争 |
| PORTER_02 | 新进入者威胁 |
| PORTER_03 | 替代品威胁 |
| PORTER_04 | 客户议价能力 |
| PORTER_05 | 供应商议价能力 |

先划定产品市场、地域和价值链位置。金融企业的资金、分销和人才也可能构成关键投入；集团不同分部不能共用一句竞争结论。五力描述行业竞争结构与盈利约束，公司的优势和优势变化仍需IQS_05、06证据；行业增长率不能替代结构分析。[哈佛商学院五力框架说明](https://www.isc.hbs.edu/strategy/business-strategy/Pages/the-five-forces.aspx)

全部12道工具题都保留1—10评分，但 `aggregation=diagnostic`，不进入维度均分或质量综合分，避免重复计分。选择工具时在profile的 `diagnostic_rationale` 写明具体疑问。没有具体疑问就不追加，full模式也不自动追加。
